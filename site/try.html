Try unidex

This is the real firmware code running in your browser, with a simulated screen and two buttons. It shows sample classes and notes; nothing here is yours and nothing is saved.

What works here

Timetable, Notes (sample notes to read), Pet, Badge, Dex, Chooser, the games and Settings run the same code as the device. What needs hardware doesn't: there is no WiFi, microphone, radio (Meet) or USB sync, so voice notes, scans, Open on phone and Meet say they aren't available. The screen refreshes instantly here; a real e-ink screen takes a moment, and the flash option imitates a full refresh.

Want the real thing? Install it on a board, or join the wait list.
