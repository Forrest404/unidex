unidex Install Tools Notes Source code

Notes

Set up voice notes: hold B in the Notes app, talk, let go. The device transcribes it with OpenAI Whisper, tidies it up with OpenAI or Claude, keeps it on the SD card and can push it to a GitHub repo (for Obsidian). Everything here goes over USB to your device only: this page has no other code and can't reach the internet. What the device sends where: Privacy (draft).

Your browser can't talk to USB devices. Use Chrome or Edge on a computer.

Plug the device in and press one of its buttons to wake it, then Connect.

Connections

Blank password and key fields keep what's saved. Test runs on the device itself, over its own WiFi.

WiFi

Logs in with PEAP / MSCHAPv2. The device doesn't check the network's certificate, so a fake access point with the same name could capture this password: use it only where you trust the network, and not with a password you use elsewhere. Adding your university's CA certificate above makes this safer.

Logs in with PEAP / MSCHAPv2 and checks that the network's certificate was signed by your CA. It can't check the server's name, so this only stops a fake access point if your university uses its own private CA. If the CA is a public one, treat the network as unchecked.
