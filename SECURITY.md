# Security

## Reporting a problem

If you find a security problem in the unidex firmware or website (for example, a way to read someone's keys or
notes, or to change a device without its owner), please report it privately rather than in a public issue:
use **Report a vulnerability** on the repository's
[Security tab](https://github.com/Forrest404/unidex/security/advisories/new). Say what you found, how to reproduce
it and which version (Settings > Battery & info > Firmware).

You'll get an answer when it has been looked at. Please give it time to be fixed before telling others.

## What's covered

The latest release only. Updates come out as new releases on GitHub and the website
(https://forrest404.github.io/unidex/); update with the website's Update button.

## Good to know

- Anyone who has the device and a USB cable can use the keys saved on it. If you lose it, revoke your OpenAI,
  Anthropic and GitHub keys.
- See [PRIVACY.md](PRIVACY.md) for what the device and website keep and send.
