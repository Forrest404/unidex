# Security

## Reporting a problem

If you find a security problem in the unidex firmware or website, please report it privately rather than in a
public issue. Examples are a way to read someone's keys or notes, or to change a device without its owner.

Use **Report a vulnerability** on the repository's
[Security tab](https://github.com/Forrest404/unidex/security/advisories/new). Say what you found, how to
reproduce it, and which version you're running (Settings > Battery & info > Firmware).

You'll get an answer once it's been looked at. Please give it time to be fixed before you tell others.

## What's covered

Only the latest release. Updates come out as new releases on GitHub and the website
(https://tools.unidex.shop/), and the website's Update button installs them.

## Good to know

- Anyone who has the device and a USB cable can use the keys saved on it. If you lose it, revoke your OpenAI,
  Anthropic and GitHub keys. Before you pass a device on, use Settings > Reset data > Factory reset.
- [PRIVACY.md](PRIVACY.md) explains what the device and website keep and send.
